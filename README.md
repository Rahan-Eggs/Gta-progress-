# 🚁 The Hour — GTA Online Daily Ops Routine

A clean, high-efficiency web utility designed for GTA Online players to manage daily business rotation circuits, track weekly bonus events, and optimize money-making sessions.

---

## 🔥 Features

* **Dynamic Day Types**: Switch between **Production**, **Heist**, **Hybrid**, and **Weekly Pick** routines depending on your available playtime.
* **Stock Tracker**: Punch in your current stock percentages for Bunker, Acid Lab, Nightclub, Hangar, and CEO Cargo Warehouses to get smart recommendations on what is actually worth selling.
* **Weekly 2X Boost Toggles**: Highlight active Rockstar Newswire bonuses to see boosted activities automatically marked with `🔥 2X`.
* **Live Weekly Reset Countdown**: Automatic countdown synced to Rockstar's Thursday weekly reset schedule (formatted for local time).
* **Local Storage Sync**: All stock inputs, completed steps, and session preferences are saved locally in your browser—no login required.

---

## 🛠️ Built With

* **HTML5 / CSS3** (Custom responsive design with dark mode styling)
* **JavaScript (Vanilla)** (Local Storage persistence & dynamic rendering)
* **Google Fonts** (*Bebas Neue* & *Inter*)

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Brave, Edge, Firefox).
